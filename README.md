# 오픽(OPIc) 원버튼 답변 트레이너

에어팟 마이크로 들려오는 오픽 질문을 듣고, Claude가 만든 AH~S급 답변을 3단어씩 끊어
읽어주는 따라 말하기 연습 앱입니다. 화면은 START 버튼 하나뿐이고, 그 뒤로는 화면 터치만으로
진행됩니다.

1. START → 에어팟 마이크로 질문 듣기 시작 (질문은 노트북 모의고사 등 외부에서 소리로 나와야 합니다)
2. 질문이 끝나면 터치 → 질문을 글로 옮기고(Whisper) 답변 생성(Claude, 문장 단위 스트리밍)
3. 답변을 3단어씩 읽어줌 → 따라 말하고 터치 → 다음 3단어 … 마지막 덩어리 뒤 자동 띵동
4. 터치 → 다시 질문 듣기 (무한 반복). 하단 종료 버튼으로 홈 복귀

## 로컬 실행

```bash
npm install
OPENAI_API_KEY=... ANTHROPIC_API_KEY=... npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 필요한 환경변수

| 이름 | 용도 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 답변 생성 (Claude) |
| `OPENAI_API_KEY` | 질문 음성 → 글 변환 (Whisper) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | 워치 알림용 웹 푸시. 없으면 최초 실행 시 자동 생성되어 `vapid-keys.json`에 저장 |

## Render로 배포하기

저장소의 `render.yaml`을 Render가 인식합니다. New + → Web Service → 이 저장소 연결 →
Build `npm install`, Start `npm start` → Environment에 위 환경변수 등록 → Deploy.
코드를 푸시하면 자동으로 재배포됩니다.

## 아이폰에서 쓰기

1. 배포된 HTTPS 주소를 Safari로 열고 공유 → **홈 화면에 추가**
2. 홈 화면 아이콘으로 실행 → START → 마이크 권한과 알림 권한 허용
3. 아이폰 설정 → 손쉬운 사용 → 음성 콘텐츠 → 음성 → 영어에서 Premium 음성을 내려받으면
   앱이 자동으로 그 음성을 씁니다

## 워치 알림에 대해

문장이 바뀔 때마다 웹 푸시로 아이폰에 알림을 보내며, iOS가 이를 애플워치로 미러링합니다.
다만 iOS 정책상 **아이폰이 잠금 해제된 상태에서는 알림이 워치가 아니라 아이폰에만** 뜹니다.
폰을 손에 들고 터치하는 동안에는 워치에 표시되지 않는다는 뜻이며, 코드로 우회할 수 없습니다.

## 한계

- 에어팟 이어폰으로 재생되는 소리는 마이크가 잡을 수 없습니다. 질문은 방 안에서 소리로 들려야 합니다.
- 홈 화면 PWA에서는 브라우저 음성 인식 API가 동작하지 않아 녹음을 서버로 보내 변환합니다.
  질문이 끝나고 첫 3단어가 나오기까지 몇 초의 처리 시간이 있습니다.
