# 오픽(OPIc) 원버튼 답변 트레이너

에어팟 마이크로 들려오는 오픽 질문을 듣고, Claude가 만든 AH~S급 답변을 한 문장씩
화면에 띄워 소리 내어 읽는 연습 앱입니다. 화면은 두 영역뿐입니다.

- **위 [답변 말하기]**: 듣기 중이면 녹음을 끝내고 답변 시작. 답변 중이면 다음 문장
- **아래 [듣기]**: 언제든 새 질문 듣기 시작

흐름: [듣기] → 질문이 방 안에서 소리로 들림(노트북 모의고사 등) → [답변 말하기] → 질문을 글로
옮기고(Whisper) 답변을 문장 단위로 스트리밍(Claude) → 문장이 화면에 뜸 → 읽고 터치 → 다음 문장
→ 마지막 문장에서 터치하면 띵동 → [듣기]로 다음 질문.

## 두 번째 화면 · 워치 리모컨

- `/display` 를 다른 폰·태블릿·노트북에서 열어두면 현재 문장이 검은 배경에 크게 실시간으로 뜹니다.
- `/watch` 는 애플워치의 간이 브라우저용(iMessage로 링크를 보내 열기)으로, 현재 문장과 함께
  [듣기]·[다음] 버튼이 있어 폰을 만지지 않고 워치에서 진행할 수 있습니다. 폰은 앱을 켠 채로
  두어야 합니다.
- ↻ 버튼(또는 `?flip=1`)으로 180° 뒤집어 마주 보는 사람이 읽게 할 수 있습니다. 같은 API
  (`GET /api/current`, SSE `GET /api/current/stream`)를 ESP32 같은 소형 디스플레이가 써도 됩니다.

## 로컬 실행

```bash
npm install
OPENAI_API_KEY=... ANTHROPIC_API_KEY=... npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 필요한 환경변수

| 이름 | 용도 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 답변 생성 (Claude) |
| `OPENAI_API_KEY` | 질문 음성 → 글 변환 (Whisper). OpenAI 계정에 결제/크레딧이 있어야 동작 |

## Render로 배포하기

저장소의 `render.yaml`을 Render가 인식합니다. New + → Web Service → 이 저장소 연결 →
Build `npm install`, Start `npm start` → Environment에 위 환경변수 등록 → Deploy.
코드를 푸시하면 자동으로 재배포됩니다. 무료 플랜은 유휴 시 잠들어 첫 요청이 느리므로
Starter 플랜을 권장합니다.

## 아이폰에서 쓰기

1. 배포된 HTTPS 주소를 Safari로 열고 공유 → **홈 화면에 추가**
2. 홈 화면 아이콘으로 실행 → [듣기] → 마이크 권한 허용

## 한계

- 에어팟 이어폰으로 재생되는 소리는 마이크가 잡을 수 없습니다. 질문은 방 안에서 소리로 들려야 합니다.
- 홈 화면 PWA에서는 브라우저 음성 인식 API가 동작하지 않아 녹음을 서버로 보내 변환합니다.
  질문이 끝나고 첫 문장이 나오기까지 몇 초의 처리 시간이 있습니다.
